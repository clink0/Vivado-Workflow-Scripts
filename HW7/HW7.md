## [cite_start]1. Basics [cite: 4]

[cite_start]Different from the UART, the SPI is a synchronous communication protocol. [cite: 5] [cite_start]Besides, communication between the transmitter and receiver is duplex. [cite: 5] [cite_start]In other words, data is transmitted and received at the same time in the SPI. [cite: 6]

[cite_start]Therefore, the SPI communication uses four wires. [cite: 7] [cite_start]Two of these wires are for data transfer. [cite: 7] [cite_start]One wire is used for the common clock signal (for synchronization). [cite: 8] [cite_start]The fourth wire is used to enable (select) signal. [cite: 8]

[cite_start]Different from the UART, data packet size is not constant in the SPI. [cite: 9] [cite_start]This is an advantage since the user can select the packet size as he or she desires. [cite: 10] [cite_start]Moreover, the dedicated common clock and enable signals avoid using start and stop bits in the UART. [cite: 11] [cite_start]The only requirement here is the need for determining the data packet size. [cite: 12] [cite_start]Hence, the transmitter and receiver can understand each other. [cite: 13]

## [cite_start]Transmission and Reception Operations [cite: 90]

[cite_start]In the SPI, the data transmission and reception is controlled by the leader through SCK and signals. [cite: 91] [cite_start]When there is no transmission, stays at logic level 1 and SCK stays either at logic level 0 or 1 depending on the SPI mode. [cite: 92]

[cite_start]The SPI communication starts when the leader wakes the follower by setting to logic level 0. [cite: 93] [cite_start]Next, the leader and follower start interchanging data in every clock cycle set by SCK. [cite: 93] [cite_start]Here, either the leader sends a bit through MOSI line or the follower sends a bit through MISO line. [cite: 94] [cite_start]The SPI mode also determines if data will be sent on the rising or falling edge of SCK. [cite: 95] [cite_start]After all bits are transferred, the common clock stops and leader deselects the follower by changing to logic level 1. [cite: 96, 97]

1.  [cite_start]**RDY:** The initial state. [cite: 107] [cite_start]It checks the condition `send == 1?`. [cite: 108] [cite_start]If false (**F**), it loops back to RDY. [cite: 106]

3.  [cite_start]**Action:** Sets `ss <= 0` [cite: 110] [cite_start]and `mosi <= data[index]`. [cite: 111]
4.  [cite_start]**TRANSMIT:** Enters the TRANSMIT state. [cite: 112]
5.  [cite_start]**Decision:** Checks `index == 0?`. [cite: 114]

6.  [cite_start]**STOP:** Sets `busy <= 0` and `ss <= 1`. [cite: 124, 126]

## Verilog Code Implementations (Page 3)

### [cite_start]Leader Transmitter [cite: 134-164, 206-231, 241-242]
```verilog
module SPI_leader_transmitter (clk, data, send, sck, ss, mosi, busy);
  parameter data_length = 6; // Note: Source 135 says 6, Source 170/314 say 8
  input clk;
  input [data_length-1:0] data;
  input send;
  output reg sck = 0;
  output reg ss = 1;
  output reg mosi;
  output reg busy = 0;

  localparam RDY = 2'b00, START = 2'b01, TRANSMIT = 2'b10, STOP = 2'b11;
  reg [1:0] state = RDY;
  reg [7:0] clkdiv = 0;
  reg [7:0] index = 0;

  always @(posedge clk) begin
    // sck is set to 2MHz
    if (clkdiv == 8'd25) begin
      clkdiv <= 0;
      sck <= ~sck;
    end else clkdiv <= clkdiv + 1;
  end

  always @(negedge sck) begin
    case (state)
      RDY: begin
        if (send) begin
          state <= START;
          busy <= 1;
          index <= data_length - 1;
        end
      end
      START: begin
        ss <= 0;
        mosi <= data[index];
        index <= index - 1;
        state <= TRANSMIT;
      end
      TRANSMIT: begin
        if (index == 0) begin
          state <= STOP;
          mosi <= data[index];
        end else begin
          mosi <= data[index];
          index <= index - 1;
        end
      end
      STOP: begin
        ss <= 1;
        busy <= 0;
        state <= RDY;
      end
    endcase
  end
endmodule
```

### [cite_start]Follower Receiver [cite: 169-204, 245-276]
```verilog
module SPI_follower_receiver(sck, ss, mosi, data, busy, ready);
  parameter data_length = 8;
  input sck;
  input ss;
  input mosi;
  output reg [data_length-1:0] data;
  output reg busy = 0;
  output reg ready = 0;

  localparam RDY = 2'b00, RECEIVE = 2'b01, STOP = 2'b10;
  reg [1:0] state = RDY;
  reg [data_length-1:0] data_temp = 0;
  reg [7:0] index = data_length - 1;

  always @(posedge sck) begin
    case(state)
      RDY: begin
        if (!ss) begin
          data_temp[index] <= mosi;
          index <= index - 1;
          busy <= 1;
          ready <= 0;
          state <= RECEIVE;
        end
      end
      RECEIVE: begin
        if (index == 0) begin
          data_temp[index] <= mosi;
          state <= STOP;
        end else begin
          data_temp[index] <= mosi;
          index <= index - 1;
        end
      end
      STOP: begin
        data <= data_temp;
        busy <= 0;
        ready <= 1;
        state <= RDY;
        index <= data_length - 1;
      end
    endcase
  end
endmodule
```
